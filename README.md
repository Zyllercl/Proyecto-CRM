# Proyecto CRM

## Descripción del proyecto
Este proyecto consistirá en crear un **CRM** en consola con **Python** utilizando **POO**. Las funcionalidades que tendrá serán las siguientes: 
- Menú interactivo
- Visualización de *Inventario*
- Visualización de *Ventas*
- Visualización de *Proveedores*
- **CRUD** de *Productos*
- **CRUD** de *Proveedores*
